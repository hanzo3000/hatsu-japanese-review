添加新內容

可以新增單詞或詞組。保存後會寫入瀏覽器，Export Code 也會包含它。

Export / Import Code

同一個 HTML、同一瀏覽器會自動保存。換瀏覽器或換電腦時，先 Export，再把 code 貼到新頁面的 Import 即可。Code 只保存收藏、刪除、自加內容與編輯，不重複塞入整個內建詞庫。

這一版怎麼整理

這一版先整理資料，再做頁面。Excel 只使用 Word 與 Phrase 兩個 tab；其他 tab 完全不收入。Project 則整理你實際問過的日語內容，能由舊圖片前後文可靠恢復的內容也一併收入。

目前共 517 個單詞卡、287 個表現 / Phrase 卡。其中 Project 整理內容 114 條，Excel Word / Phrase 清洗後內容 690 條。

原始資料中的重複、錯字、混在同一格的內容已重新整理。例如「しっかり / がっしり / きちんと」現在拆成三張獨立單詞卡；明顯誤記會在整理註記中說明，而不是照抄。

舊圖片：已失效的圖片無法逐張重新打開，因此只收入能從當時提問與上下文可靠恢復的內容，不猜測圖片裡看不到的文字。

詞頻：星級是日常學習優先級，不是假裝精確的語料庫統計。外部實例改用 YouGlish Japanese。
